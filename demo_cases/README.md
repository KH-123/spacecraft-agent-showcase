## 展示边界

- 输出仅用于概念 / 初步设计辅助。
- 不声称生成最终工程设计、飞行认证结果或型号研制结论。
- RAG-enhanced LLM advisor 只提供只读设计建议，不回写参数，不替代 validation、orbit_consistency、Core Orbit Gate 或 deterministic tools。
- 文档描述的是预期行为，不伪造截图、日志或工具数值结果。
